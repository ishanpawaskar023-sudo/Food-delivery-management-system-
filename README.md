# Food-delivery-management-system-
Food Delivery Management System

A modern and interactive Food Delivery Management System built using HTML, CSS, and JavaScript. The project provides a complete dashboard for managing food orders, menu items, delivery riders, and basic analytics.

Features

 Order Management

- Create new food orders
- Add customer name and delivery address
- Add multiple food items to an order
- Mark orders as Rush Orders
- Automatically calculate the total order amount
- Track orders through different stages:
  - New
  -  Preparing
  -  Out for Delivery
  -  Delivered

Menu Management

- Add new food items
- Select food categories
- Set item prices
- Toggle item availability
- Remove menu items
- Manage sold-out items

Rider Management

- View all delivery riders
- Track rider status:
  - Available
  - On Delivery
  - Offline
- Automatically assign available riders to outgoing orders
- Track the number of deliveries completed by each rider
- Manage rider availability

Analytics Dashboard

- View orders based on their current status
- Display order distribution using progress bars
- View top-selling menu items
- Track sales performance

Dashboard Statistics

The system displays important real-time statistics such as:

- Total Orders
- Total Revenue
- Average Preparation Time
- Riders On Duty

 Responsive Design

- Modern dark-themed user interface
- Responsive layout for desktop, tablet, and mobile devices
- Interactive navigation tabs
- Dynamic order tickets
- Real-time clock

 Technologies Used

- HTML5 – Structure of the application
- CSS3 – Styling and responsive design
- JavaScript (ES6) – Application logic and interactivity

 How to Run the Project

1. Download or clone the repository.
2. Open the project folder.
3. Open the "food-delivery-management.html" file in any modern web browser.

No additional installation or dependencies are required.

 Main Modules

1. Order Board

The order board helps track orders from creation to delivery.

New → Preparing → Out for Delivery → Delivered

2. Menu

Allows administrators to manage food items, categories, prices, and availability.

3. Riders

Displays delivery riders and their current working status.

4. Analytics

Provides insights into order status and top-selling food items.
